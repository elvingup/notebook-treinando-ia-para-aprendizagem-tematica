# Caderno Temático "Bradesco Data Science: AI and Cybersecurity Research Framework"

O atual projeto é um caderno da plataforma *Google Gemini Notebook* cujo objetivo é estudar e compreender a utilização de tecnologias de *Inteligência Artificial e Cibersegurança para Ciência de Dados* pelo Banco Bradesco. Assim, o caderno compila conceitos básicos de *Inteligência Artificial*, *Cibersegurança* e *Ciência de Dados* para estudá-los e tentar entender a correlação entre eles. Então, tal conhecimento pode ser cruzado com informaçõe específicas do *Banco Bradesco*, visando estudar os possíveis casos de uso que seriam aplicáveis aos projetos dele hoje em dia.

OBJETIVO = [ ... ] ;

DEMANDA = [ Faça o seguinte: ... ] ; preciso que a DEMANDA seja satisfeita de modo completo e minucioso, conforme informado.

DÚVIDA = [ ... ] ; pesquise as fontes para compilar as informações concernentes à DÚVIDA. Daí, responda a DÚVIDA de modo assertivo: sempre visando uma tomada de decisão objetiva, bem-informada e bem-fundamentada.

EXIGÊNCIA = [ Regras: § ... / ] ; o resultado a ser produzido de modo sistemático deve incluir cada uma das Regras da EXIGÊNCIA. Também: o resultado deve descartar as informações e implicações excluídas pela EXIGÊNCIA.
